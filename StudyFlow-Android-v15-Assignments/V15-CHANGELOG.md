# StudyFlow v15 — Scanner Removed + Assignments

- Removed the COR/class-program photo scanner and all scan/review/import code.
- Removed the Tesseract.js dependency.
- Manual class entry remains the supported way to add schedule data.
- Expanded the existing academic events system with a dedicated Assignment workflow.
- Assignments support title, subject, due date, time, priority (High/Medium/Low), location, description, and reminders.
- Assignment priority is shown in the Events list.
- Existing data format remains compatible; older events without a priority simply default to Medium when edited as assignments.
