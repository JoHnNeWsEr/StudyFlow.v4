# StudyFlow v36

## Fixes
- Theme changes now update the Home header design instead of leaving the default purple header.
- Added distinct header gradients for Light, Dark, Midnight, Ocean, Forest, Sunset, Rose, and Minimal themes.

## Study Goal History
- Completed goals remain saved with their completion date.
- Completed History is now collapsed by default inside Manage Goals.
- Added a View/Hide button to expand the history inline.
- Expanded history stays inside a compact scrollable panel instead of opening a separate full-screen page.
- Restore remains available for completed goals.
