# StudyFlow v28

## Home countdown and event visibility fix
- Home now keeps incomplete events visible until the user marks them done, including events whose scheduled time has already passed.
- Future events show a live countdown to the scheduled start. Overdue events show a live elapsed overdue timer.
- Home Study & Goals renders the live Focus countdown directly beside the exact goal when that goal is being focused.
- Focus countdown continues to update every second while the Home screen is rendered.
- Existing Event completion animation and behavior are unchanged.
