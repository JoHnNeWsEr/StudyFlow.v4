# StudyFlow v47 — Goal ⋯ Menu Cleanup

- Removed the combined goal-options editor/start/delete flow.
- Each active goal's `•••` menu now contains exactly:
  - Start
  - Edit duration
  - Delete
- Start immediately begins Focus for that exact goal and returns to the app dashboard with its live countdown.
- Edit duration changes only that goal's saved Focus duration.
- Goal History remains intact, including Restore and View all history.
- No scanner, Grades, Academic Calendar, or StudyFlow Server changes.
