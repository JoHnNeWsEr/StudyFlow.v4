# Get StudyFlow on your Android phone

1. Create a free GitHub account and a new repository.
2. Upload ALL files from this folder (including the hidden `.github` folder; if the web uploader skips it, use GitHub Desktop or drag the folder contents).
3. Open the repo's **Actions** tab -> **Build Android APK** -> **Run workflow** (it also runs on every upload). Takes ~5 minutes.
4. Open the finished run, download the **StudyFlow-apk** artifact, unzip it.
5. Send app-debug.apk to your phone, tap it, allow "Install unknown apps".
6. On first reminder, allow notifications when Android asks.
