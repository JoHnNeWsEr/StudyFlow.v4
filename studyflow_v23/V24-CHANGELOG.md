# StudyFlow v24 — Home Completion + Event Countdown

## Changes
- Reused the Event-category completion animation for Home completion interactions.
- Added the same check pop/draw, burst/confetti, vibration and card-pulse effect to Study & Goals completion.
- Home event completion now uses the same shared completion animation helper as the Events page.
- Removed the large black Focus button from the Study & Goals header.
- Kept Focus attached to the specific Study & Goals item; its live Focus countdown remains beside that goal.
- Removed Focus controls from Home's Upcoming Events cards so they are not mistaken for the event countdown.
- Added a live countdown on each Home Upcoming Event showing time remaining until that event's scheduled date/time.
- The Home event countdown updates every second.

## Preserved
- Event-category behavior and data handling remain intact.
- Dedicated Events page remains unchanged in behavior.
- Existing Focus/background notification implementation remains intact.
- Scanner, Grades, and Academic Calendar are not reintroduced.
