# StudyFlow v37

## Tutorial rebuild
- Rebuilt the guided tutorial positioning from scratch.
- Header step now highlights the header and places the guide card underneath it.
- Tutorial cards use stable safe-area placement instead of covering highlighted controls.
- Updated tutorial steps to target the actual controls for goals, Focus, subjects, schedule, events, reminders, themes, and backup.
- Removed the misleading old final tutorial step and replaced it with a useful Backup & Restore step.

## Completed goal history
- Completed goals now show a compact preview of the latest three entries in Manage Goals.
- View all expands the full completed-goal list inside the Study Goals & Focus modal.
- Show less collapses the expanded history back to the three-item preview.
- Restore remains available for each completed goal.
