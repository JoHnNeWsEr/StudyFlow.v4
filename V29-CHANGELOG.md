# StudyFlow v29

## Home Focus targeting
- Tapping Focus beside a specific Study Goal always attaches the live session to that exact goal.
- If a focus session is already running, selecting a goal retargets the existing live session to that goal and refreshes its native notification label.

## Home Upcoming Events
- Home now shows unfinished events only on their exact calendar date.
- Events scheduled for tomorrow or later remain available in Events but are not shown in Home yet.
- At 12:00 AM on the event date, the event appears on Home and its live countdown starts toward the event time.
- Unfinished events remain visible on that date after their scheduled time so they can still be marked done.
